# AI Tools and Usage

## 1. GitHub Copilot

Purpose:
- repository inspection
- project understanding and code review
- implementation of the photo-flow changes and assessment-related updates
- debugging the MongoDB startup issue in the test environment
- generation and refinement of automated tests
- assistance with documentation and assessment file preparation

Examples of usage:
- reading and summarizing the backend and frontend structure
- identifying the correct files for route, auth, and UI changes
- proposing test cases for invalid inputs and status validation
- helping structure the required assessment documents

Human review/validation:
- all generated modifications were checked against the existing project behavior
- test results were run in the actual environment and reviewed before completion

## 2. ChatGPT

Purpose:
- requirement interpretation for the assessment checklist
- planning documentation and evidence structure
- testing strategy and validation planning
- demo script drafting and presentation outline

Examples of usage:
- breaking the assessment requirements into explicit phases
- aligning the documentation deliverables with the actual repo state
- planning the red/green evidence workflow and required final-report structure

Human review/validation:
- all planning suggestions were cross-checked against the actual repo and code behavior before being used

## 3. Important honesty note

This project used the AI tools listed above to assist with repository understanding, implementation, testing, and documentation. No tool usage was claimed beyond what was actually used in this work.
